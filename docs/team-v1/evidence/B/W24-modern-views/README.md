# W24 · measured Modern view evidence

The JPG images are offline renders of production BMH meshes using the same measured Modern fixture, collection and saved furniture placements. They are not AI-generated architecture. Scene extraction loads the actual licensed GLB chair and final production material/light settings. The result.json records source hashes, scene counts, revisions, image hashes and test provenance.

The public collection thumbnail is derived from living.jpg and carries its own provenance. All visible furniture stays inside the saved measured envelope. No extra cabinet, terrace guard or structural detail is drawn without corresponding plan data. Explicit saved customer furniture remains; an unconfirmed terrace receives no generated furniture.

These images support review of material/geometry consistency. Cycles/AgX and offline fill differ from browser rendering. This environment has no enabled browser WebGL context; native GPU appearance and mobile performance remain unverified.

## Remaining acceptance gates

- Kitchen/bedroom detail still falls below the selected photoreal reference. Improve measured components and source-approved assets, keeping the shared plan and material identities.
- Terrace guard, drainage, waterproofing and structural inputs are unknown and not visually invented.
- Generic finishes are not verified manufacturer SKU replicas or supplier quotations.
- Customer/architect visual acceptance and native GPU verification remain open.

An incremental production release fixes the listed defects; it does not mean that Modern R1 or all 24 styles are commercially approved.

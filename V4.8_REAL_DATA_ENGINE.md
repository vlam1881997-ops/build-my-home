# Build My Home V4.8 — Real Data Engine

V4.8 keeps the V4.7 planner/optimizer/3D workflow and replaces hidden fixed estimate constants with a source-aware data layer.

## Added
- Live current weather via Open-Meteo with explicit live/fallback status.
- 12-month historical climate cross-check via Open-Meteo Historical Weather API.
- Official-reference catalogue for Ministry of Construction and local price publications.
- Source-aware cost basis for shell, finishes and site preparation.
- Regional/labor planning factors shown to the user instead of hidden in the formula.
- JSON/CSV supplier quote import; imported quotes are tagged by supplier/date/reference.
- Per-material price overrides from imported quotes.
- Estimate snapshots with timestamp, location, unit rates, source and total.
- `real-data-engine.json` included in the project ZIP export.
- Step 8 now displays the exact cost basis used for the estimate.

## Important commercial note
Government publications are reference/benchmark sources. Exact purchase prices must come from a dated supplier/contractor quote or another verified source. The UI intentionally labels planning baselines and live data separately.

## Quote import
Use `PRICE_QUOTE_TEMPLATE.csv`, or JSON with fields such as `source`, `date`, `reference`, `shellPerM2`, `finishPerM2`, `prepPerM2`, and `materials`.

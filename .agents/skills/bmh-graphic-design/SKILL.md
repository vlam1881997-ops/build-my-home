# BMH graphics

Read [visual assets and evidence](references/visual-assets.md).

Establish whether the graphic is an interface icon, diagram, illustration, sample interior or evidence of the user's actual design. Keep its role explicit; read the existing logo and app tokens.

- Start from BMH warm neutral surfaces and restrained green/teal actions. Define a small token set for text, borders, background, action, error and focus; keep spacing and typography consistent across desktop, phone and print.
- Make exact interface icons/small diagrams with SVG/CSS. Share viewBox/stroke weight, use round joins/currentColor and accessible labels; mark decorative SVG aria-hidden. Retain functional text.
- Match symbols to real actions. Avoid checkmarks suggesting engineering approval or payment success.
- Clarify hierarchy with spacing/alignment/typography before decoration.
- Label collection imagery as sample rooms. Use a current measured-model screenshot with matching revision and camera for a customer's actual perspective.
- Use the available image-generation tool for requested raster images/edits, real references and intended use; follow bmh-images for faithful perspective/material work. Do not invent a connected Figma/CAD/Blender service.
- Use bmh-drawings for exact sheets and bmh-3d for measured geometry; never fabricate dimensioned plans using image generation.
- Confirm provenance and redistribution rights for external customer assets. A public image URL alone does not establish permission.
- Optimize for use: SVG icons, sized thumbnails, bounded textures/GLB, readable print with units and preliminary status retained.

Inspect desktop, phone and exported cover/sheets at actual size. Check clipping, contrast, missing glyphs, mixed symbols, sample/current-image confusion and reduced motion. Keep app code/assets in its Git repository; persist standalone requested artifacts through the normal durable workflow.

Report delivered visual changes and unverified licences/references directly. A graphic skill is not a software integration or paid-service capability.
